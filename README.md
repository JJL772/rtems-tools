# Misc. RTEMS Tools

Miscellaneous RTEMS, scripts, tools and other utilities.

## Features

* CMake toolchains for cross compiling for RTEMS via CMake.
* Misc utilities (mkrootfs, bin2as, fix-clangdb, etc.)

## Tools

### `fix-clangdb.py`

Applies fixups to `compile_commands.json` files that are generated by tools such as `bear`.

Removes unsupported arguments and adds implicit compiler include/lib paths to make it work well with clangdb.

### `mkuboot.sh`

> USAGE: mkuboot.sh -f FILE -o OUT -a ARCH -l LOADADDR [-r RTEMS_VER]

Generates U-Boot bootable image files.

`ARCH` may be powerpc, aarch64, arm, etc.

### `cmake_configure.py`

Utility and library that generates CMake toolchains and configures for build.

## CMake Usage

cmake/rtems.cmake contains a number of helpers for working with RTEMS in CMake. They are documented throughout that file.

To build a basic application for RTEMS 7 pc686 using CMake, you might write a CMakeLists.txt with the following contents:
```
# Assuming this is submoduled in under tools/
include(tools/cmake/rtems.cmake)
rtems_cmake_init()

add_executable(
    myApp src/rtems_init.c
)
```

And then you'd configure and build with:
```
./tools/cmake_configure.py
make -C build
```

**cmake_configure.py** will generate toolchain files for you automatically, based on the pkgconfig files installed by RTEMS. 
**This is the preferred method of CMake configuration.**

### Legacy Toolchains

Legacy toolchains can be found in the toolchains directory.

These can be used like this:
```
cmake . -Bbuild-i386-rtems -GNinja -DCMAKE_BUILD_TYPE=Release -DCMAKE_EXPORT_COMPILE_COMMANDS=ON -DCMAKE_TOOLCHAIN_FILE=path/to/this/repo/toolchains/rtems6-pc686.cmake
```

The flags provided in the toolchain files comes from the generated Makefile.cfg produced by RTEMS.
